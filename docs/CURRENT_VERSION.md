# 当前版本和适用范围

| 项目 | 当前值 |
|---|---|
| Python 包 | `dex-frax 1.0.4` |
| 运行环境 | 支持 Python 3.11、3.12，推荐使用约束文件对应的 Python 3.12 |
| 输入 | BVH、SMPL-X |
| 目标和频率 | Dex 31 轴，含头部 yaw、pitch，50 Hz |
| 默认转换模式 | `fast` 预览 |
| 默认脚接触 | `v2` |
| 默认精修路线 | A |
| `refine` 默认时限 | 无共享精修时限和外层总时限，单次候选有求解时限 |

源码包提供 Python 源码、使用文档、依赖约束文件和 Dex 机器人资产。wheel 提供转换器和 Python 包内配置，运行时使用配套的 Dex 31 轴资产目录。输入动作、人体模型和人体表面几何按对应输入类型准备。 [安装](../README.md#安装和运行) · [输入](INPUTS.md)

终验范围覆盖离线运动学、配置的模型几何与有限间隔的帧间采样。真实硬件上的平衡、执行效果和动作库的适用性需要按使用场景独立验证。 [验收规则](SAFETY_REPAIR_RULES.md)
