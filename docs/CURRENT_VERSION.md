# 当前版本和适用范围

| 项目 | 当前值 |
|---|---|
| Python 包 | `dex-frax 1.0.4` |
| 运行环境 | 支持 Python 3.11、3.12，推荐使用约束文件对应的 Python 3.12 |
| 输入 | BVH、SMPL-X |
| 目标和频率 | Dex 29 轴，50 Hz |
| 默认转换模式 | `fast` 预览 |
| 默认脚接触 | `v2` |
| 默认精修路线 | A 基线，B、C 可显式选择用于测试 |
| 默认精修时限 | 原始整条输入换算到 50 Hz 的总帧数 × 0.5 秒 |

源码包提供 Python 源码、使用文档、依赖约束文件和 Dex 机器人资产。wheel 提供转换器和 Python 包内配置，机器人资产使用同版本源码包中的 `assets/dex_evt`。输入动作、外部人体模型和参考几何按各自来源准备。 [安装](../README.md#安装和运行) · [输入](INPUTS.md)

终验范围覆盖离线运动学、配置的模型几何与有限间隔的帧间采样。真实硬件上的平衡、执行效果和动作库的适用性需要按使用场景独立验证。 [验收规则](SAFETY_REPAIR_RULES.md)
